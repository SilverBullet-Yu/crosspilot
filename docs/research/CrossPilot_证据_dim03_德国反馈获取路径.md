# 维度 03｜德国侧反馈的合法获取路径（对应清单 P0-1）

核对日期：2026-11-18

## 说明：本维度能做什么、不能做什么

清单 P0-1 要求的是**一组真实的、有市场归属依据的德国侧反馈样本**。这类样本属于品牌私有或需授权取得的数据，公开调研无法代为产生。本维度的作用是：把「可以怎样合法拿到」这件事查清楚，让你方照着走，并明确标出哪些路线不可用。

**本维度不产出任何德国消费者反馈样本。清单 P0-1 的四个勾选项在本次调研后仍全部为空。**

## 3.1 四条候选路径及其许可条件

| 路径 | 能否满足「本品 + 德国归属 + 可授权」 | 许可依据与前置条件 | 评估 |
| --- | --- | --- | --- |
| **A. 品牌自有德国站评论 / 售后反馈** | **能**（最优） | 品牌作为数据控制者，自有客户反馈；需品牌书面授权用于内部分析、模型处理、赛事演示三项用途 | **推荐主路线**。市场归属由订单/店铺站点确定，不依赖语言判断 |
| **B. Amazon 官方品牌侧数据** | **能，但门槛高** | 需 Amazon Brand Registry 注册 + Brand Analytics Selling Partner API 角色[^sp]；Customer Feedback API 提供的是主题、趋势与片段，不是完整评论档案 | 仅当合作品牌本身已注册品牌并愿意授权 API 角色时可用；黑客松周期内大概率来不及 |
| **C. 第三方采集/数据集服务** | **不推荐** | 采集服务自述只采公开数据，但 Amazon 条款普遍禁止未授权自动化采集；且有公开报告称评论分页自 2026 年 5 月起需登录才能访问 | **演示阶段不采用**。与赛事「严禁批量爬取」条款叠加后风险不可控 |
| **D. 公开学术/行业数据集** | **部分可用，但不满足本品归属** | 需逐个核对数据集许可证与地域标注 | 只能作为背景参考，不能充当「本品德国反馈」 |

## 3.2 GDPR 口径：公开 ≠ 可自由处理

这是本项目最容易被忽视的合规点，须写进方案：

1. **公开可见的评论若包含个人数据，仍落入 GDPR 范围**，无论用户是否自愿公开[^zenodo]。
2. 从第三方网站（而非数据主体本人）收集个人数据时，适用 **GDPR 第 14 条的告知义务**；第 14(5) 条的「不合比例的努力」例外并非研究用途的概括豁免——波兰数据保护机构在 Bisnode 案中就以此为由对一家从公开来源抓取数据的公司作出罚款[^zenodo]。
3. 若依赖「正当利益（legitimate interests）」作为处理依据，需完成并留档**正当利益评估（LIA）**，包括目的测试、必要性测试与平衡测试[^lia]。
4. 处理前必须先确定并记录合法性基础，不能事后补justification[^lia]。

**对本项目的直接含义：**
- 路径 A（品牌自有数据）下，品牌是控制者，CrossPilot 是处理者，需要的是**数据处理协议 + 明确的用途授权**，而不是「用户点了同意上传」。
- 展示前必须去除评论者昵称、头像、主页链接等可识别信息——这与清单第三条「展示前去除可识别的个人信息」一致。
- 采用路径 C 时，第 14 条告知义务无法履行，这是比「平台条款」更难解决的问题。

## 3.3 「德语文本 ≠ 德国市场」的操作化判据

清单明确要求记录市场归属依据。建议在证据卡中固定以下字段，缺一即标为「归属不明」：

| 字段 | 可接受取值 | 不可接受 |
| --- | --- | --- |
| 站点/渠道 | amazon.de、品牌德国官网、德国经销商售后系统 | 「德语评论」 |
| 归属依据 | 订单配送国、店铺站点、受访者居住地声明 | 文本语言 |
| 采集时间 | 具体日期 | 「近期」 |
| 样本量 | 具体条数 | 「若干」 |
| 本品/竞品 | 明确标注 | 混记 |
| 许可范围 | 内部分析 / 模型处理 / 赛事演示（分别记录） | 「已授权」 |

## 3.4 清单各项当前状态

| 清单项 | 状态 | 阻塞原因 |
| --- | --- | --- |
| 拿到至少一组真实反馈并记录归属依据 | **未满足** | 无品牌授权数据源；需你方对接品牌方 |
| 标明本品还是竞品 | **未满足** | 依赖上一项 |
| 确认三类许可范围并分别记录依据 | **未满足** | 需品牌方书面授权；建议同时签数据处理协议 |
| 选取容量/便携相关原文并写明能/不能说明什么 | **未满足** | 依赖上一项 |

**开工判据判定：** 清单写明「没有合格的德国侧反馈时，不将真实跨市场证据对照标为通过」。按当前证据，**该项不通过**。

## 3.5 可执行的解除路径（按优先级）

1. **本周内**：向目标合作品牌提出三项请求——① 一组德国站真实反馈导出（含站点与时间字段）；② 书面授权书，分列内部分析/模型处理/赛事演示三类用途；③ 脱敏后的商品资料。这三项同时也解决 P0-3 的第二个勾选项。
2. **若品牌方无法提供**：改为访谈取证。由运营或其德国渠道伙伴提供 3–5 条有明确来源记录的售后反馈转述，按 3.3 的字段登记，并在证据卡上标注证据等级为「间接转述」。
3. **两条都不成立时**：按方案 4.3 的既有承诺，演示全程使用标注清楚的模拟数据，并在路演中**主动说明**真实德国侧证据尚未取得——这比被评委问出来更安全，也符合手册的原创与诚信要求。

## 一、结论速览

| 数据源 | 许可 | 与本项目相关性 | 处置 |
|---|---|---|---|
| 知乎开放平台 | 平台条款 | **高**（L2 核心信息源） | 已实查，维持 3.5/4 |
| DATA.GOV.HK | 商用免费，仅禁转售 | **低** | 降级为背景语境，不进对照矩阵 |
| 深圳开放平台 | 免费，禁转让 | **极低** | **移出数据栈** |

**核心发现：两个政务平台均无法支撑「德国消费者偏好」这一核心命题，原清单对其定位偏乐观。**

## 二、DATA.GOV.HK（原清单：有条件，许可最宽松）

### 2.1 许可已核实，优于原记录

| 项 | 核实结果 |
|---|---|
| 商用 | 明文允许，免费，政府不收取费用与版税 |
| 唯一禁止 | 转售下载所得数据 |
| 强制义务 | 注明数据来源、确认政府知识产权、向政府作出弥偿 |
| 条款版本 | 第 1.2 版，最后更新 2025-05-26 |
| 平台更名 | 「资料一线通」已更名为「开放数据平台」 |

许可宽松度确实如原清单所述，**但相关性不成立**。

### 2.2 致命缺口：十大出口目的地无德国

浏览器实访 Table 410-50013（政府统计处，2026-10-28 发布）取得完整名单：

> 中国内地、美国、越南、台湾、印度、阿联酋、日本、泰国、马来西亚、新加坡

**德国不在其中，且无任何欧洲国家入列。**

| 影响 | 说明 |
|---|---|
| 不可用于 | 德国市场体量、品类结构、消费者偏好 |
| 仅可用于 | 「出海目的地集中于亚太、德国非主流通道」这一反向背景论据 |
| 层级 | L3，按硬约束 1 不得单独支撑偏好结论 |

### 2.3 技术备注

- 统计处提供独立 JSON API（`censtatd.gov.hk/api/get.php`，参数 id/lang/period/sv/sp）。
- **直连返回 403**（Azure Application Gateway WAF 拦截 Python 默认 UA）。若后续确需接入，须走浏览器上下文或配置合规 UA；赛期内不建议为低相关数据投入此成本。

## 三、深圳市政府数据开放平台（原清单：API 需审批，审批周期不可控）

### 3.1 接入流程已核实

| 环节 | 实际要求 |
|---|---|
| 注册 | 个人／机构，广东省统一认证平台 |
| 取 Key | 提交应用 → 订阅接口 → 审核通过后个人中心查看 appKey |
| 调用 | `opendata.sz.gov.cn/api/{数据集ID}/1/service.xhtml?page=&rows=&appKey=` |
| 分页 | rows 单页上限 10000；支持 startDate／endDate 过滤 |
| 格式 | CSV／XLS／JSON／XML／RDF |

原清单「审批周期不可控」判断成立，**但这已不是主要问题**。

### 3.2 唯一相关数据集实访结果

「深圳市商务局-跨境电商公共海外仓信息」（ID `29200_05600038`）：

| 指标 | 实测值 |
|---|---|
| 数据量 | **3 条** |
| 数据容量 | 9 |
| 更新日期 | 2022-11-28（四年未更新） |
| 德国覆盖 | **无** |
| 字段 | 海外仓所在国家、仓库数量、建设面积 |

其余贸易类数据集（统计月报-对外贸易、口岸进出口货值、南山区进出口总额等）均为**深圳本地宏观总量**，无国别拆分、无品类拆分、无消费者侧信息。

### 3.3 许可附加约束

平台条款第四项明确：用户**不得有偿或无偿转让**从平台获取的任何数据资源；须在成果中注明来源为「深圳市政府数据开放平台」。此条与产品未来商业化路径存在潜在摩擦，但因数据本身已不采用，不构成实际风险。

## 四、对方案的影响

| # | 影响项 | 建议改动 |
|---|---|---|
| 1 | 清单 1.3「DATA.GOV.HK 承载港澳双语境」 | 港澳语境与「德国市场」首个场景无关；若坚持保留，须明确标注为 L3 背景，且不得进入对照矩阵 |
| 2 | 清单 1.3 深圳开放平台 | 建议直接移出数据栈。不是审批慢的问题，是无相关数据 |
| 3 | 落地检查表 | 第 6 项（Eurostat 德国切片）优先级应高于任何国内政务平台 |
| 4 | 路演叙事 | 「十大出口目的地无德国」可作为**主动说明时效与覆盖缺口**的诚实素材，强于回避 |

**国内侧可用数据源实际仅知乎一家。** 这进一步放大了已知风险：知乎属 L2，按硬约束 1 不能单独支撑偏好结论；而 L1 德国侧仍为零样本。开工判据依旧卡在 P0-1 与 P0-3，本轮检索未能改变该判定。

## 分段录制备忘

- 镜 2/3/5/8 用 fixtures 模式即可完成，互相独立；镜 6 的「新词降级黄条」必须 API 模式（fixtures 不走后端），两条路径：
  1. 真实录屏：`NUXT_PUBLIC_API_BASE=http://localhost:8000 npm run dev` 重启前端后录；
  2. 现场风险高时：改用截图或备用录屏片段插入（黄条样式见 `docs/demo/演示说明.md` 第三节）。
- 每镜开始前刷新页面（Ctrl+Shift+R），避免上镜的页面状态残留。
- 镜 4 的两张德语卡若观众看不清，可临时放大浏览器缩放至 125% 录特写，录完改回 100%。
- 成片自查：对照 `docs/demo/演示说明.md` 第四节合规清单逐条勾选后再发布（重点：演示标识可见、不与真实卡混排、快照时效口径有一句旁白）。
- 镜 2 旁白已按 2026-11-21 真实快照口径修正（L2 为 2026-11-18 真实采集片段、无演示标识）——不得沿用旧稿「演示数据」表述，避免成片与代码不一致。
- 镜 7 画面为 `docs/demo/validation_log.md` 文本展示，无 UI 依赖；录制前确认该文件在位，字号调大（≥16pt）保证录屏可读。
- 时长红线：成片 ≤180 秒；超时优先压镜 1 与镜 8 的旁白，不压镜 3–5 的状态展示。

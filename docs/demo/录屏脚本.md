# CrossPilot 2.0 录屏脚本（≤3 分钟）

> 总时长目标 **≤180 秒**（红线 180 秒；2026-11-21 增补镜 7 闭环镜后重排）。按镜分段录制，每镜标注对应场景参数，可独立重录。
> **ADR-0005 扩卡注记（2026-11-22）**：演示场景已扩卡（conflict 32 张 / limited 30 张），判定为四值公式（conflict→conflicting、limited→supported），判定依据收进横幅「判定依据」折叠区。镜 4/5 旁白按扩卡口径；录制时展开「判定依据」特写（公式是可信度卖点）。
> **界面基线（2026-11-25）**：多页外壳 + 浅色判定横幅（判定依据默认收起）+ 左「产品与假设」/ 中「证据对照」/ 右「下一步验证建议」三栏 + 底部默认折叠的「中文侧经验（L2 · 知乎）」；演示证据每组默认只展示 1 张，点「展开全部」看余下。镜 2–6 的画面/操作列已按当前界面重写。
> 录制前置：前端 fixtures 模式（默认，不依赖后端与网络）；浏览器窗口 ≥1500px 宽，缩放 100%；先关闭首次进入的 3 步使用引导（点「稍后再说」），顶栏保持「日间」皮肤（需固定夜间可在 URL 加 `theme=night`）；再按 `docs/demo/演示说明.md` 第二节验收清单确认画面正确。
> 旁白为逐字稿，可直接念；方括号内为录制提示，不念。

## 分段录制备忘

- 镜 2/3/5/8 用 fixtures 模式即可完成，互相独立；镜 6 的「新词降级黄条」必须 API 模式（fixtures 不走后端），且需展开底部「中文侧经验（L2 · 知乎）」折叠区才可见，两条路径：
  1. 真实录屏：`NUXT_PUBLIC_API_BASE=http://localhost:8000 npm run dev` 重启前端后录；
  2. 现场风险高时：改用截图或备用录屏片段插入（黄条样式见 `docs/demo/演示说明.md` 第三节）。
- 每镜开始前刷新页面（Ctrl+Shift+R），避免上镜的页面状态残留；首次进入工作台先点「稍后再说」关闭 3 步引导，避免遮挡画面。
- 镜 4 的两张德语卡若观众看不清，可临时放大浏览器缩放至 125% 录特写，录完改回 100%。
- 成片自查：对照 `docs/demo/演示说明.md` 第四节合规清单逐条勾选后再发布（重点：演示标识可见、不与真实卡混排、快照时效口径有一句旁白）。
- 镜 2 旁白已按 2026-11-21 真实快照口径修正（L2 为 2026-11-18 真实采集片段、无演示标识）——不得沿用旧稿「演示数据」表述，避免成片与代码不一致；2026-11-25 界面改版后 UI 措辞按本脚本为准。
- 镜 7 画面为 `docs/demo/validation_log.md` 文本展示，无 UI 依赖；录制前确认该文件在位，字号调大（≥16pt）保证录屏可读。
- 时长红线：成片 ≤180 秒；超时优先压镜 1 与镜 8 的旁白，不压镜 3–5 的状态展示。
- 若后续界面再改，先按 `docs/demo/演示说明.md` 第二节重跑 fixtures 验收，再重录对应镜头。

# CrossPilot 2.0 录屏脚本（≤3 分钟）

> 总时长目标 **≤180 秒**。界面基线：多页外壳 + 每条卖点独立判定横幅 + 左「产品与假设」/ 中「证据对照」/ 右「下一步验证建议」三栏 + 底部「跨来源附录」。
> 演示场景使用模拟 L1 + 模拟 L2；真实场景使用真实知乎快照与 L3，德国 L1 在取得品牌授权或 Amazon 书面许可前保持零样本。Amazon.de 公开评论候选因平台条款禁止未经书面许可的系统性提取、数据挖掘与商业再利用而否决，自动提取数据已删除。窄屏自动切换为三 Tab，录制建议窗口 ≥1500px。
> 录制前置：fixtures 模式（默认，不依赖后端与网络）；先关闭首次进入的 3 步使用引导；按 `docs/demo/演示说明.md` 第二节验收清单确认画面。旁白为逐字稿，方括号内为录制提示，不念。

| 1 开场·问题 | 0:00–0:20 | — | 卖家盯着「大容量？多隔层？低价？」三个卖点选项打问号 | 无 | 做德国站的卖家，每天都在猜：首屏到底主打大容量，还是多隔层，还是低价？猜错一次，就是一版详情页重做加一轮退货。跨境卖家缺的不是文案，是能对得上号的目标市场消费者证据。 |

## 分段录制备忘

- 镜 2–5、8 用 fixtures 模式即可完成；镜 6 必须使用 API 模式，fixtures 模式只切换固定场景，不检索任意商品。
- 每镜开始前刷新页面，避免假设编辑、Tab 与滚动状态残留；首次进入先关闭 3 步引导。
- 镜 4 的德语卡若观众看不清，可临时放大浏览器缩放至 125% 录特写，录后改回 100%。
- 成片自查：对照 `docs/demo/演示说明.md` 第四节逐项勾选；重点检查模拟标识、跨来源附录、非随机样本边界与「运营试用待执行」表述。
- 不得沿用旧稿「总体证据相互冲突」「limited 单卖点已有有限支持」「演示场景没有 L2」等表述，这些已与当前代码不一致。

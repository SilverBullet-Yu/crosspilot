# ADR-0002 演示默认走本地快照

状态：已接受 ｜ 日期：2026-11-18

## 背景

2026-11-18 实测本账号知乎配额：搜索 `TotalQuota=10`（手册称 5000）、热榜 2、直答 2。排练一次加评委体验两三次即耗尽。路演现场还叠加网络与限流风险。

## 决策

1. `CROSSPILOT_DATA_MODE` 默认 `snapshot`，只读 `data/snapshots/`；`live` 需显式开启。
2. 演示前预跑「旅行收纳包 → 德国」并落盘快照。
3. 快照中的来源链接保留真实可点开的原始页面，保持可追溯感。
4. 额度耗尽必须给出明确降级提示，禁止静默返回空结果（手册提交前检查第 7 条要求）。

## 后果

- 正面：演示不依赖现场网络与配额。
- 代价：快照有时效性，须在路演中主动说明数据截止时间，优于被评委问出。

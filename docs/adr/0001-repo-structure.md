# ADR-0001 单仓双应用 + 领域层隔离

状态：已接受 ｜ 日期：2026-11-18

## 背景

赛期短、人少、交接频繁，且四条数据许可硬约束一旦在代码中被绕过，属于不可挽回的合规事故而非普通 bug。

## 决策

1. **单仓库 `apps/api` + `apps/web` 双应用**，共享 `packages/contracts`。不拆多仓：赛期内跨仓同步契约的成本高于收益。
2. **规则下沉到 `domain/`**，该层不依赖 FastAPI、不发网络请求。路由与适配器只做编排。
3. **硬约束写成可执行测试**（`tests/test_constraints.py`），不是文档约定。违反即红灯。
4. **数据源注册表是唯一闸门**：未登记的数据源无法通过 `assert_usable`，新增必须同步改 `docs/CONSTRAINTS.md`。

## 后果

- 正面：合规规则可回归、可交接；新人改路由不会意外绕过许可闸门。
- 代价：领域层与适配器之间多一层转换，小改动需动两处。赛期规模下可接受。

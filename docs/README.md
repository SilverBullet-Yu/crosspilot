# CrossPilot 文档索引

> 最后更新：2026-11-26（交接材料迁入 `docs/`）

## 交接入口

1. 先读 `status/STATUS.md`（唯一事实来源）。
2. 启用或接入数据前读 `checklists/CrossPilot_接入数据与启用前操作清单.md`。
3. 需要理解产品方案与需求时读 `requirements/`（`prd/`、`data/`、`deliverables/`）。
4. 需要复核证据与报告时读 `research/`、`reports/`。

## 开发文档

| 目录 | 内容 |
|---|---|
| `adr/` | 架构决策记录，一个决策一个文件 |
| `demo/` | 演示 Runbook、录屏脚本与验证日志 |
| `devlog/` | 开发日志，赛事创作真实性佐证 |

## 路径约定

文档中的 `apps/`、`docs/`、`data/`、`scripts/` 等开发路径均相对仓库根目录。

# 硬约束与合规红线

本文件是评审清单，不是参考资料。任何 PR 若触碰下表场景，必须在描述中逐条回应。

## 一、数据许可硬约束

| # | 约束 | 触发场景 | 违反后果 | 代码落点 |
|---|---|---|---|---|
| 1 | 知乎内容归 L2，不得单独支撑「消费者偏好」结论 | 向对照矩阵写入 stance | 二手转述与一手反馈同权，范畴错误 | `domain/evidence.py`、`services/datasets.py:assert_demand_side` |
| 2 | MARC 商业化路径启动即下线 | ¥99—199 定价成立时 | 违反 Amazon 学术限定条款 | `services/datasets.py` |
| 3 | OPUS 只取 ParaCrawl，排除 OpenSubtitles | 拉取语料时 | 底层字幕条款不明，商用受限 | `services/datasets.py` |
| 4 | Comtrade 必须注册免费账号 | 任何贸易数据调用 | 截断与完整返回外观一致，500 行可掩盖 4 万行 | `services/datasets.py` |
| 5 | DeepL API Free 档禁止传入含个人数据的文本 | 翻译评论原文、用户名、联系方式 | Free 档无 DPA，文本可能用于改进服务，构成 GDPR 问题 | `services/datasets.py` |

## 一之二、扩展源调用纪律（2026-11-20 新增）

| 来源 | 纪律 | 原因 | 代码落点 |
|---|---|---|---|
| eBay Browse | 返回内容只进「企业假设」栏，不得写入消费者证据侧 | 是卖家自撰文案，非消费者反馈 | `assert_demand_side`（`seller_side_only`） |
| eBay Browse | 5,000 次/日按 AppKey + API 名聚合，不按 marketplace 拆分 | DE 与 US 共用同一额度 | 适配器配额守卫 |
| GDELT | 请求间隔 ≥5s；单查询 ≤250 条，不得视为全量 | 与硬约束 4 同类截断失败模式 | `page_limit=250` |
| HF Dataset Viewer | `/rows` `/filter` 单次 ≤100 行，必须显式分页 | 同上 | `page_limit=100` |
| OpenAlex | 不再使用 `mailto` 参数；`per_page` ≤100，基础分页 ≤10,000 条 | 2026-02 起 polite pool 废弃，参数被忽略 | `page_limit=100` |
| EU Safety Gate | 自由文本须剔除邮箱、电话、私人挂牌链接 | 警报描述产品而非个人，但文本可能夹带个人数据 | 适配器清洗层 |

## 二、证据层级定义

| 层级 | 含义 | 代表来源 | 能否单独支撑偏好结论 |
|---|---|---|---|
| L1 | 目标市场一手消费者反馈 | Amazon Reviews 2023（**美国市场试点**，不构成德国 L1）、品牌授权导出 | 可以 |
| L2 | 中文从业者经验、二手转述 | 知乎 | **不可以**，只能生成待验证问题 |
| L3 | 宏观统计与市场语境 | Eurostat、Comext、Safety Gate | **不可以**，仅作背景 |

## 三、证据卡必现六字段

原文摘录、来源链接（可真实打开）、语言、日期、证据层级、样本量。缺任一字段的证据卡不得渲染。

## 四、赛事合规

| 项 | 要求 |
|---|---|
| 创作真实性 | 留存 AI 交互记录、设计底稿、开发日志；主办方有权核验，无佐证取消资格 |
| 参赛资格 | 已在其他竞赛获奖或已公开发布的项目不得参赛 |
| 内容红线 | 禁搬运、抄袭、外包代做、一稿多投；禁未授权使用第三方商标、IP、人像、版权素材 |
| 爬取 | 手册明文严禁批量爬取与滥用站内用户数据；知乎侧只做实时检索 + 摘录引用 + 链接回源，不建全文库 |
| 模拟数据 | 演示界面、视频、计划书中的模拟回填必须带显式「演示数据」标识，且不与真实反馈同卡混排 |
| 提交窗口 | 12-05 10:00 — 12-07 10:00，逾期不接受任何修改替换 |

## 五、GDPR 要点

公开可见评论若含个人数据仍受 GDPR 约束；自第三方来源收集适用第 14 条告知义务，第 14(5) 无针对非研究用途的概括豁免。依赖「正当利益」须完成并留档 LIA。因此第三方采集路径不采用，品牌自有授权数据为唯一推荐主路线。
